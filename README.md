# 中国植物资源选育程序虚拟仿真

这是一个可部署的静态网页版原型，用于模拟从天然林、资源圃或地方群体开始的植物选育程序。

## 功能

- 选择中国代表性植物资源，包括用材林木、果树经济林、油料饮料植物、观赏植物和药用植物。
- 从天然群体中点击候选单株，录入树高、胸径、冠幅、材积、干性、抗病、抗旱等指标。
- 果树和经济林自动显示果实相关品质指标，如单果重、可溶性固形物、硬度、果色、单株产量、含油率等。
- 每个育种阶段都有仿真动画和必须点击完成的操作点，完成本步骤互动后才能进入下一步。
- 覆盖天然林调查、优树选择、种源试验、创造新遗传变异、遗传测定、优良新品种选择、种子园建立、采穗圃建立、良种繁育、生产应用和循环改良。
- 按物种选择指数计算综合评分，保存优株并推进后续育种程序。
- 支持导入 JSON 资源数据，后续可批量接入中国生物物种名录、iPlant/中国植物志或地方种质资源清查数据。
- 支持导出本轮选育记录 JSON。

## 运行与部署

直接打开 `index.html` 即可运行。也可以把整个目录上传到任意静态网站服务：

- GitHub Pages
- 学校或实验室 Web 服务器
- Nginx/Apache 静态目录
- 对象存储静态网站托管

部署时需要保留这些文件：

- `index.html`
- `styles.css`
- `script.js`
- `species-data.js`
- `assets/forest-breeding-hero.png`

## 扩展完整中国植物资源

完整“中国植物资源”不建议手工写入页面。推荐流程是：

1. 从中国生物物种名录、iPlant/中国植物志、Flora of China 或本单位资源清查表获取结构化名录。
2. 清洗为 `species-data.js` 中相同字段：`id`、`name`、`scientific`、`family`、`type`、`region`、`habitat`、`objective`、`fruit`、`weights`。
3. 通过页面左侧“导入资源 JSON”追加，或直接合并进 `species-data.js` 后部署。

## 教材内容对齐

项目中已包含《林木育种学 第二版（陈晓阳）》PDF。该 PDF 当前识别为扫描版，普通文本提取无法直接得到正文。网站已先按该教材的林木育种学 12 章知识框架组织理论学习模块，并为每章生成 PPT 学习点和拓扑学习结构图。

后续若安装中文 OCR 或提供可复制文本版教材，可继续逐页提取目录、章标题、节标题和正文摘要，把理论学习模块精修为严格逐章逐节版本。建议继续细化的实验包括：种源试验设计、优树综合评分、半同胞/全同胞子代测定、无性系测定、选择指数计算、控制授粉、种子园建园与去劣疏伐、采穗圃复壮、扦插/嫁接/组培繁殖和良种苗木质检。

## 访问与学习统计

当前项目为纯静态网页，已加入本地浏览器端访问次数和参与学习次数统计。若部署后需要统计所有用户的真实在线访问人数和学习人数，需要增加后端接口或数据库服务，例如学校服务器 API、Firebase/Supabase、或自建 Node/Python 统计接口。
